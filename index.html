Дерево решений

Интерактивное введение в алгоритм CART с визуализацией границ решений

Введение

Что такое дерево решений?

Дерево решений — алгоритм машинного обучения, который принимает решения по принципу последовательных вопросов. Модель пытается «разделить» данные на всё более однородные группы, пока в каждой не останутся объекты одного класса.

Структурно дерево похоже на обычную блок-схему: в вершине задаётся вопрос, в зависимости от ответа идём влево или вправо, затем следующий вопрос — и так до конечного ответа. Например: «Температура выше 20°C?» → Да: «Влажность высокая?» → Нет: «Играть в теннис». Именно поэтому это один из самых понятных алгоритмов — его логику можно буквально прочитать глазами.

Деревья решений применяются повсюду, где нужно принимать решения на основе данных:

  • банковский скоринг и антифрод-системы;
  • медицинская диагностика;
  • рекомендательные алгоритмы;
  • классификация изображений и текстов;
  • игровой AI и системы поддержки принятия решений.

Кроме того, деревья решений стали фундаментом для более мощных ансамблевых алгоритмов: Random Forest, Gradient Boosting, XGBoost, LightGBM и CatBoost.

Алгоритм

Как строится дерево?

Дерево строится рекурсивно сверху вниз функцией buildTree. На каждом шаге алгоритм:

  1. Проверяет, одинаковы ли все ответы — если да, создаёт лист дерева и останавливается.
  2. Проверяет условия остановки: глубина ≥ 5 или менее 3 объектов в выборке.
  3. Ищет лучшее разделение данных по всем признакам и возможным порогам.
  4. Делит датасет на две части относительно найденного порога.
  5. Рекурсивно строит поддерево для каждой части.

Дерево растёт слой за слоем: каждая вершина получает свой кусок данных, находит оптимальный вопрос и порождает двух потомков.


function buildTree(dataset, labelFeature, depth = 0){
    let values = [];
    for (const i of dataset){
        let value = i[labelFeature]
        values.push(value)
    }
    let unique = [...new Set(values)]
    if (unique.length === 1){
        return unique[0]
    }
    if (depth >= 5){
        return findMajorClass(dataset, labelFeature)
    }
    if (dataset.length <= 3){
        return findMajorClass(dataset, labelFeature)
    }
    let a = findBestSplit(dataset, labelFeature)
    let b = split(dataset, a.bestFeature, a.bestThreshold)
    let left = buildTree(b.left, labelFeature, depth + 1)
    let right = buildTree(b.right, labelFeature, depth + 1)
    return {
        feature: a.bestFeature,
        threshold: a.bestThreshold,
        left: left,
        right: right
    }
 }

Дерево нельзя строить бесконечно — иначе модель идеально «запомнит» тренировочные данные, но окажется бесполезной на новых. Это называется переобучением. Поэтому введены два ограничения: по глубине (depth >= 5) и по объёму выборки (dataset.length <= 3). В обоих случаях возвращается наиболее частый класс в оставшихся данных — findMajorClass().

Критерий разбиения

Коэффициент Джини

Коэффициент Джини показывает, насколько «перемешаны» классы внутри группы. Идеальная группа из объектов одного класса даёт Джини = 0. Полностью перемешанная группа — максимальное значение, близкое к 0.5 (для двух классов).

Формула: G = 1 − Σ pᵢ², где pᵢ — доля класса i в группе. Например, для группы [1, 1, 1, 0]: p(1) = 3/4, p(0) = 1/4, значит G = 1 − (3/4)² − (1/4)² = 0.375. Чем ближе к 0 — тем чище группа.

Функция findBestSplit перебирает все признаки и все возможные пороги, вычисляет взвешенный коэффициент Джини для каждого разделения и сохраняет наилучший вариант:

// Функции, для подсчета коэффицента Джини и разбиения.
function gini(points, feature) {
    // Получаем некоторый массив со всеми значениями некоторых свойств
    let values = []
    const count = {}
    for (const point of points){
        let a = point[feature]
        values.push(a)
    }
    let unique = new Set(values) // С помощью класса сет получаем объект хранящий уникальные значения массива values
    // Этим циклом считаем количество в массиве values этих уникальных значений, например если массив будет [1, 0, 0, 0, 1] то мы получим count = {1 : 2, 0: 3}
    for (const i of unique){
        count[i] = 0
        for (const j of values){
            if (i == j){
                count[i] += 1
            }
        }
        }
    // Находим сумму, которая используется в коэффиценте Джини: 1 - sum(веротностей)
    let sum = 0
    for (const k of unique){
        let p = count[k] / values.length
        sum += p**2
    }
    return 1 - sum
}

function findBestSplit(dataset, labelFeature){
    // Вводим это чтобы потом обновлять их значения
    let bestGini = 1;
    let bestFeature = null;
    let bestThreshold = null;


    let features = Object.keys(dataset[0]).slice(0, -1) // dataset[0] - это первый элемент массива, в нашем массиве это будет weather: 1, temp: 22, label: 1; я благодаря Object.keys мы получаем массив уникальных свойств
    // features - это массив всех свойств нашего датасета, помимо последнего, тк подразумевается, что наши датасеты всегда имеют 'label', как последний столбец (тут наверно надо придумать что-то другое)
    for (const feature of features){
        let values = [];
        for (const i of dataset){
            let a = i[feature];
            values.push(a);
        }
        const unique = [... new Set(values)].sort((a, b) => a - b);
        /*
        Вообщем, опять получаем все уникальные значения values; сортируем массив, нужно это для чего: так как нам нужно лучшее разделение, мы должны впринципе проверить все возможные разделения
        посчитать для них коэффицент Джини и выбрать с наименьшим коэффицентом, если у нас данные типа [9, 12, 15, 17], то в какой-то книжке я вычитал, что обычно проверяют по средним арифметическим
        идущим друг за другом элементам, то есть a = (9 + 12) / 2, делят на две части, где значения меньше a и больше a; считаем для каждого коэффицент Джини, после этого считаем взвешеннный коэффицент
        Джини т.к. количество значений может отличаться, поэтому я сортирую массив по возрастанию, чтобы удобнее считать средние арифметические.
        */
        let temps = [];
        for (let i = 0; i < unique.length - 1; i++ ){
            let temp = (unique[i] + unique[i+1]) / 2;
            temps.push(temp);
        }
        // Посчитали все возможные средние арифметические, теперь итерируемся по ним, делим и считаем коэффицент Джини, перезаписывая bestGini, bestFeature, bestThreshold
        for (const threshold of temps){
            const result = split(dataset, feature, threshold)
            let gLeft = gini(result.left, labelFeature)
            let gRight = gini(result.right, labelFeature)
            let g = (result.left.length / (result.left.length + result.right.length)) *gLeft + (result.right.length / (result.left.length + result.right.length)) * gRight
            if (g < bestGini){
                bestGini = g;
                bestFeature = feature;
                bestThreshold = threshold;
            }
        }

    }
    return {bestFeature, bestThreshold}
}

Пороги перебираются в серединах между соседними значениями признака: для значений [15, 18, 21, 25] проверяются пороги 16.5, 19.5 и 23. Между двумя соседними значениями результат разбиения не меняется, поэтому достаточно проверять только середины.

Взвешенный коэффициент Джини учитывает размер каждой группы — если слева 90 объектов, а справа 10, их вклады нельзя считать одинаковыми. Алгоритм CART использует именно Джини, а не энтропию: он быстрее вычисляется и даёт сопоставимые результаты на практике.

Предсказание

Как дерево делает предсказание?

После обучения дерево уже содержит готовые правила. Предсказание — это проход по дереву сверху вниз: в каждой вершине проверяется условие, и в зависимости от ответа переходим в левое или правое поддерево, пока не достигнем листа с конечным ответом.

// Функция предсказания
function predict(node, point){
    if (typeof node !== 'object' || node === null) {
        return node
    }
    if (point[node.feature] > node.threshold) {
        return predict(node.right, point);
    } else {
        return predict(node.left, point)
    }
}

Если текущий узел не является объектом — это лист, функция возвращает метку класса. Иначе проверяется условие: если значение признака объекта больше порога, идём вправо, иначе — влево. Рекурсия продолжается, пока не дойдём до листа.

Например, для объекта {temp: 25, humidity: 40} при правиле «temp > 20 → humidity > 60»: сначала 25 > 20 (да → вправо), затем 40 > 60 (нет → влево) — получаем ответ. Именно так дерево решений превращает набор правил в конкретное предсказание.
